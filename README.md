# 🚀 Nova AI

Nova AI is a modern AI chatbot built with **Python, Flask, Google Gemini API, SQLite, HTML, CSS and JavaScript**.

It provides a ChatGPT-style conversational interface with streaming AI responses, chat history, Markdown rendering, syntax-highlighted code blocks and a modern glassmorphism UI.

## ✨ Features

- 🤖 AI-powered conversations using Google Gemini
- ⚡ Streaming AI responses
- 💬 ChatGPT-style chat interface
- 🗂️ Persistent chat history
- ➕ Create new conversations
- 🗑️ Delete conversations
- 📝 Markdown response rendering
- 💻 Syntax-highlighted code blocks
- 📋 Copy code functionality
- 🎨 Modern dark glassmorphism UI
- 🌌 Animated Aurora background
- 🔐 Environment-variable based API key configuration
- 🗄️ SQLite database for chat storage
- 📱 Responsive interface
